# Overview
This repository contains the code used to perform genomics and transcriptomics analysis from manuscript:

[Oliveira, D. S., et al. "Transposable elements contribute to the evolution of host shift–related genes in cactophilic Drosophila species." Genome Research 36.3 (2026): 487-505.](https://genome.cshlp.org/content/36/3/487.short)

### Instructions and file descriptions:

- [Differential expresssion analysis](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/Differential-expression)
- [Gene annotation](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/Gene-annotation)
- [Permutation tests](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/Permutation-test)
- [Positive selection test](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/Positive_selection_test)
- [TE annotation](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/TEannotation)
- [Transcription factor binding sites analysis](https://github.com/OliveiraDS-hub/Pipelines-Cactophilic-Drosophila-Species/tree/main/TFBSs_analysis)
